# Lending decision platform

Mortgage decisioning on the national HMDA data (2023 to 2025): a PySpark and Delta Lake pipeline, a
TensorFlow model with a fair-lending audit and adverse-action reasons, real-time serving through TF Serving,
decision events through Pub/Sub into BigQuery, drift and fairness monitoring, Terraform for GCP and a
Databricks Asset Bundle.

Work in progress: built in sprints, see the [milestones](https://github.com/Tajaddin/lending-decision-platform/milestones).
